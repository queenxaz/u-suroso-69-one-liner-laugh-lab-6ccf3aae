One short funny line answering a prompt: the excuse a robot vacuum gives
after eating a sock. Entry for the
[One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae)
competition on [make.fun](https://make.fun).

## The line

> In my defence, you did say "pick up everything on the floor" — the sock simply believed in me.

The joke is literal obedience: the vacuum did exactly what it was told,
and the sock is the one that trusted the instruction. Deadpan, no setup
that overstays, 94 characters.

## How it works

`main.py` writes the line to `/output/entry.txt` — nothing else. It is
fully deterministic: no network, no randomness, no environment reads.

```sh
python3 main.py
cat /output/entry.txt
```
